# iOS Liquid Glass Launcher

A native Android launcher starter project inspired by the translucent glass surfaces, soft gradients, colorful rounded icons and dock of modern iOS. This is an independent Android project, not Apple's software.

## Build an APK from your phone
1. Download and extract this ZIP.
2. Create a GitHub repository in your phone browser.
3. Upload the extracted project files, including the hidden `.github` folder.
4. Open the repository's **Actions** tab.
5. Choose **Build Liquid Glass Launcher APK** and tap **Run workflow**.
6. When the run finishes, download the `liquid-glass-launcher-apk` artifact.
7. Extract that artifact ZIP and tap `app-debug.apk` to install. Allow installation from your browser/files app if Android asks.
8. Press Home and choose **Liquid Glass Launcher** as the default Home app.

## Included
- iOS-inspired translucent glass panels and dock
- Gradient rounded app icons
- Date/time and weather-style widget
- Light/dark appearance toggle
- Search bar and app shortcuts
- Home launcher intent

## Notes
- This is a starter launcher. Icon glyphs are rendered as text and may vary by font/device; this does not replace system Control Center, notification shade, lock screen, or iOS system apps.
- A full live blur effect depends on Android version and device rendering; this starter uses translucent glass-like surfaces and gradients for compatibility.
- Requires Android 8.0 (API 26) or newer.
